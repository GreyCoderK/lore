# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Lore, please report it responsibly.

**Do NOT open a public issue.**

Instead, use **GitHub's private vulnerability reporting**:
👉 https://github.com/GreyCoderK/lore/security/advisories/new

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected version(s)

You will receive an acknowledgment within 48 hours. We will work with you to understand and address the issue before any public disclosure.

If GitHub Security Advisories are unavailable to you, you can also reach the maintainers via the contact methods listed on the GitHub organization page.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older versions | No |
